# Caption Finder

> 이 번역은 AI가 작성했으며 원어민의 검토를 거치지 않았습니다. 앱은 이 언어로도 제공되며, 버튼과 메뉴의 이름은 앱에 표시되는 그대로 적었습니다 (언어는 Account & Settings → Language에서 바꿀 수 있습니다). 불분명한 부분은 [영어 README](../../README.md)를 기준으로 삼아 주세요.

YouTube 동영상에서 문장이 말해지는 순간을 찾고, 마음에 드는 장면을 골라, 잘라낸 클립을 다운로드하세요.

문장을 입력하고 앱에 채널 하나, 여러 채널 또는 동영상 목록을 지정하면 자막을 살펴봅니다. 일치하는 결과가 왼쪽 목록에 채워집니다. 하나를 선택하면 오른쪽에 동영상이 로드되며, 해당 줄 주변에 시작점과 종료점이 이미 설정되어 있습니다. 조정하고 미리 보기한 뒤 그 부분만 다운로드하세요.

## 설치 (Windows)

[릴리스 페이지](https://github.com/MolecularDust/Caption-Finder/releases)에서 설치 프로그램을 받으세요: `Caption-Finder-Setup_<version>_x64.exe`. x64 PC의 Windows 11이 필요합니다. 앱이 사용하는 WebView2 런타임은 Windows 11에 포함되어 있습니다.

1. Caption Finder가 실행 중이면 닫습니다.
2. 설치 프로그램을 더블클릭합니다. 코드 서명이 되어 있지 않아 Windows가 알 수 없는 게시자의 앱이라고 경고할 수 있습니다. **추가 정보**(More info)를 클릭한 다음 **실행**(Run anyway)을 클릭합니다.
3. 옵션 하나를 선택합니다:
   - **Install normally:** 관리자 권한 없이 사용자 계정용으로 설치합니다. 시작 메뉴 바로 가기와 설치된 앱 목록(Apps & features)의 항목을 추가합니다.
   - **Portable:** 앱을 원하는 폴더(예: USB 드라이브)에 복사합니다. 시작 메뉴나 레지스트리에는 아무것도 추가되지 않으며, 설정은 앱 옆의 `Data` 폴더에 보관됩니다.
4. **Install**을 클릭한 다음 **Finish**를 클릭합니다.

일반 설치를 제거하려면 설치된 앱 목록(Apps & features)을 사용하세요. 설정과 로그인 데이터는 사용자 프로필에 그대로 남습니다.

같은 페이지에서 `Caption-Finder-Windows-Portable.zip`을 내려받을 수도 있습니다. 먼저 ZIP 전체를 폴더에 압축 해제한 다음 `Caption Finder.exe`를 실행하세요. ZIP 안에서 바로 실행하지 마세요.

## 설치 (macOS)

[최신 릴리스](https://github.com/MolecularDust/Caption-Finder/releases)에서 `Caption-Finder-Installer.dmg`를 받아 엽니다. 창에 단계가 표시됩니다:

1. **Install Caption Finder**를 더블클릭합니다.
2. macOS가 실행을 막습니다(“열 수 없습니다”). **완료**(Done)를 클릭합니다.
3. 파란색 **Open System Settings** 타일을 더블클릭하고, **시스템 설정**(System Settings)의 **개인정보 보호 및 보안**(Privacy & Security) 맨 아래로 스크롤한 다음 **그래도 열기**(Open Anyway)를 클릭합니다.
4. 암호로 확인한 다음 **계속**(Continue)과 **설치**(Install)를 클릭합니다.

이 앱은 임시(ad hoc) 서명이며 공증(notarization)을 받지 않았으므로 macOS가 설치 프로그램을 한 번 차단합니다. 설치 프로그램이 배치한 앱은 다운로드한 것으로 표시되지 않으므로 Caption Finder 자체는 차단 없이 열립니다. Apple silicon의 macOS 11 이상이 필요합니다.

## YouTube 접근 설정

1. Caption Finder를 설치하고 **계정 및 설정**를 엽니다.
2. **동영상 플레이어 계정**에서 **1. Google에 로그인**을 클릭하고 이어서 **2. YouTube 연결**를 클릭한 다음, 묻는 경우 채널을 선택합니다. 끝나면 계정 창을 닫습니다.
3. **다운로드 인증**에서 **앱의 YouTube 세션**을 선택합니다.

이제 Caption Finder를 사용할 준비가 되었습니다.

대신 이미 로그인해 둔 브라우저를 사용하려면 **다운로드 인증**에서 그 브라우저를 선택하세요. Windows에서는 검색하기 전에 그 브라우저를 닫으세요. Chromium 계열 브라우저는 실행 중에 쿠키 파일을 잠그므로, 거기서는 앱 자체 세션이 안정적인 선택입니다. macOS에서는 브라우저를 닫을 필요가 없습니다. 본인 계정만 사용하세요. 다른 사람의 쿠키를 가져오거나 공유하지 마세요.

**익명**를 그대로 둘 수도 있지만, YouTube의 봇 차단 검사가 익명 접근에는 더 엄격하여 일부 동영상은 실패합니다.

## 사용 방법

**검색 대상**는 모드를 선택합니다.

- **채널:** 이름을 입력하면 일치하는 채널 목록이 나타납니다(Enter를 누르면 즉시 표시). 하나를 클릭해 추가합니다. 채널 링크나 `@handle`은 바로 추가되고, 붙여넣은 동영상 링크는 해당 동영상이 속한 채널을 제안합니다. 여러 채널은 차례로 검색되거나 섞여서(각 채널에서 한 편씩 번갈아) 검색됩니다. Account & Settings를 참고하세요.
- **동영상:** 동영상 링크(watch, `youtu.be` 또는 Shorts)를 하나 또는 여러 개 붙여넣습니다. 목록의 동영상은 순서대로 검색됩니다.

그런 다음 **검색 문구**를 입력하고 **검색**를 누릅니다. 결과는 찾는 대로 나타나며 최신 순으로 최대 25개의 동영상까지 표시됩니다. 하나를 클릭하면 열립니다. 각 결과에는 일치하는 줄과 그 동영상의 일치 횟수가 표시됩니다.

오른쪽에는 플레이어, 일치한 줄, 타임라인, 여백과 길이가 있는 **시작 설정 / 끝 설정**, **Precise Cut**, **선택 범위 미리보기**, 파일 이름이 있습니다. 다운로드 폴더를 선택하고 선택 구간을 다운로드 대기열에 추가하세요. 대기열은 일시 중지, 다시 시작, 취소, 재시도, 그리고 **파일 보기**을 지원합니다. **파일 보기**은 완료된 파일을 Windows에서는 파일 탐색기에, macOS에서는 Finder에 표시합니다.

**프리셋**는 채널이나 동영상 목록을 저장해 나중에 다시 불러올 수 있게 합니다. 목록이 비어 있는 동안에는 **프리셋 저장**이 비활성화됩니다. **프리셋 불러오기**은 프리셋 폴더를 열어 파일을 선택하게 합니다. 각 모드에는 자체 프리셋이 있습니다. 프리셋 이름을 마우스 오른쪽 버튼으로 클릭하면 Load, Add to current list, Show in Finder, Rename, Remove from list를 사용할 수 있습니다. 빈 공간을 마우스 오른쪽 버튼으로 클릭하면 Clear files, Clear presets, Show presets folder를 사용할 수 있습니다. 행에서 프리셋을 제거해도 그 파일은 삭제되지 않습니다. Windows에서 **Finder에서 보기**는 이 이름을 그대로 유지하지만 프리셋 파일이 선택된 상태로 파일 탐색기를 열며, **프리셋 폴더 보기**는 폴더를 파일 탐색기에서 엽니다.

### 일치 방식

- 대소문자, 구두점, 아포스트로피 모양은 무시됩니다. 문장은 인접한 자막 구간에 걸쳐 있어도 됩니다.
- 띄어쓰기가 없는 언어(중국어, 일본어, 태국어 등)는 글자 단위로 일치시킵니다. 아랍어와 히브리어의 모음 부호는 무시됩니다.
- 자막 언어는 문구의 문자 체계를 따릅니다(키릴 문자 문구는 러시아어, 우크라이나어 등의 트랙을 찾습니다). 라틴 문자의 경우 각 동영상에서 말하는 언어를 따릅니다. 설정의 **자막 언어**가 이를 덮어쓰며, 일부 채널이 게시하는 더빙 오디오 트랙에도 적용됩니다.
- **자막에서 검색**는 검색을 업로드된 자막, YouTube 자동 자막, 또는 둘 중 아무거나(업로드된 자막 우선)로 제한합니다. 번역은 사용되지 않습니다.
- 경계는 자막 구간의 경계이며 단어 단위 정렬이 아닙니다.

### Account & Settings

- **동영상 플레이어 계정:** **1. Google에 로그인**, **2. YouTube 연결**(묻는 경우 채널 선택), **재생 확인**은 플레이어용 별도 계정 창을 엽니다. 로그인은 앱 자체의 브라우저 저장소에 보관됩니다. YouTube에서는 계정 아바타가 로그인되었음을 확인해 주며, 계정 메뉴로 계정을 바꾸거나 로그아웃할 수 있습니다. 끝나면 창을 닫고 다시 검색해 플레이어를 새로 불러옵니다.
- **다운로드 인증:** 자막 조회와 다운로드가 YouTube 로그인을 어디서 가져올지 정합니다. **익명**(기본값), **앱의 YouTube 세션**, 앱이 이 컴퓨터에서 찾은 브라우저, 또는 **Netscape 쿠키 가져오기…** 중에서 선택합니다. 쿠키는 앱 설정에 복사되지 않습니다.
  - **Windows:** Chrome, Edge, Firefox, Brave, Chromium, Vivaldi, Opera가 감지됩니다.
  - **macOS:** Chrome, Opera, Vivaldi, Firefox, Safari 등이 감지됩니다.
- **Windows에서:**
  - 브라우저의 쿠키로 검색하거나 다운로드하기 전에 백그라운드 프로세스까지 포함해 브라우저를 완전히 닫으세요. Chromium 계열 브라우저(Chrome, Edge, Opera, Brave, Vivaldi, Chromium)는 실행 중에 쿠키 파일을 잠급니다. 앱이 브라우저의 쿠키 데이터베이스를 복사하지 못했다고 알려 주면 이것이 이유입니다.
  - Windows의 Chromium 쿠키 암호화 때문에 그래도 추출이 막힐 수 있으며, 앱은 이를 우회하지 않습니다. 대신 **앱의 YouTube 세션**이나 **Netscape 쿠키 가져오기…**를 사용하세요.
  - 앱은 시스템의 수동 HTTP 프록시(사용자 이름과 암호 없음)를 yt-dlp에 전달하며 `HTTP_PROXY`와 `HTTPS_PROXY`를 따릅니다. PAC 스크립트나 로컬 주소 외의 항목이 있는 예외 목록은 전달되지 않습니다.
  - 다운로드 폴더와 가져온 쿠키 파일은 전체 경로로 저장됩니다. 포터블 사본을 다른 드라이브 문자로 옮겼다면 다시 선택하세요.
  - 다운로드를 일시 중지하면 해당 프로세스가 중단되므로 오래 멈추면 YouTube가 연결을 끊을 수 있습니다. 일시 중지와 다시 시작은 앱을 다시 시작하면 유지되지 않습니다.
  - Windows에는 전체 디스크 접근(Full Disk Access)이 없으므로 아래의 macOS 도움말 창은 나타나지 않습니다.
- **macOS에서:** Chrome과 Firefox 쿠키에는 **전체 디스크 접근**(Full Disk Access)이 필요합니다. 앱은 시스템 설정(System Settings)으로 끌어다 놓을 아이콘이 있는 작은 도움말 창을 엽니다.
- Windows가 저장할 수 없는 **파일 이름**(`CON`이나 `NUL` 같은 예약된 이름, `? * | < >` 같은 문자)은 모든 플랫폼에서 거부되므로 클립을 양쪽 사이에서 옮길 수 있습니다.
- **검색마다 살펴볼 동영상 수**(채널당, 기본값 50), **여러 채널의 결과**, **자막 언어**, **자막에서 검색**.
- **처음 찾은 동영상을 자동으로 재생하지 않기**, 그리고 **동영상을 불러오는 동안**(썸네일 또는 스피너).

## 데이터 저장 위치

| 항목 | Windows(일반 설치) | macOS |
| --- | --- | --- |
| 설정(다운로드 폴더, 인증) | `%APPDATA%\com.mike.captionfinder\settings.json` | `~/Library/Application Support/com.mike.captionfinder/settings.json` |
| 프리셋 | `%APPDATA%\Caption Finder\Presets\Channels` 및 `...\Videos` | `~/Library/Application Support/Caption Finder/Presets/Channels` 및 `.../Videos` |
| 앱 자체의 YouTube 로그인 | `%LOCALAPPDATA%\com.mike.captionfinder\EBWebView` | `~/Library/WebKit/com.mike.captionfinder` |

Windows에서는 캐시와 미디어 로그(안전한 진단 코드만 담긴 `logs\media.jsonl`)도 `%LOCALAPPDATA%\com.mike.captionfinder` 아래에 있습니다. 포터블 사본(포터블 ZIP 또는 설치 프로그램의 **Portable** 옵션)은 설정, 로그인, 캐시를 `Caption Finder.exe` 옆의 `Data` 폴더에 보관하며, 로그는 `Data\Diagnostics`에 둡니다. 프리셋은 여전히 `%APPDATA%\Caption Finder\Presets`에 저장됩니다. 포터블 폴더는 앱이 닫혀 있을 때만 옮기세요.

프리셋은 일부러 앱 자체의 폴더 밖에 보관됩니다. 초기화하거나 다시 설치해도 영향을 받지 않습니다. 앱은 묻지 않고 프리셋 파일을 삭제하거나 덮어쓰지 않으며, 파일을 교체하면 이전 버전이 `<name>.json.bak`으로 옆에 남습니다.
