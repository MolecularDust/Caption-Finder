# Caption Finder

> คำแปลนี้เขียนโดย AI และยังไม่ได้รับการตรวจโดยเจ้าของภาษา แอปมีภาษานี้ให้ใช้ด้วย และชื่อปุ่มกับเมนูในที่นี้เขียนตามที่แอปแสดง (เปลี่ยนภาษาได้ที่ Account & Settings → Language) หากมีข้อสงสัย ให้ยึด [README ภาษาอังกฤษ](../../README.md) เป็นหลัก

ค้นหาช่วงเวลาที่มีการพูดวลีหนึ่งในวิดีโอ YouTube เลือกฉากที่คุณชอบ แล้วดาวน์โหลดคลิปที่ตัดแล้ว

พิมพ์วลี ชี้แอปไปที่ช่องหนึ่งช่อง หลายช่อง หรือรายการวิดีโอ แล้วแอปจะสแกนคำบรรยายของวิดีโอเหล่านั้น ผลที่ตรงกันจะเติมเต็มรายการทางซ้าย เลือกหนึ่งรายการ แล้ววิดีโอจะโหลดทางขวาพร้อมจุดเข้าและจุดออกที่ตั้งไว้รอบบรรทัดนั้นแล้ว ปรับจุดเหล่านั้น ดูตัวอย่าง แล้วดาวน์โหลดเฉพาะส่วนนั้น

## การติดตั้ง (Windows)

รับตัวติดตั้งจาก[หน้ารุ่นที่ปล่อย](https://github.com/MolecularDust/Caption-Finder/releases): `Caption-Finder-Setup_<version>_x64.exe` ต้องใช้ Windows 11 บนพีซี x64 รันไทม์ WebView2 ที่แอปใช้มีมาพร้อมกับ Windows 11 อยู่แล้ว

1. ปิด Caption Finder หากกำลังทำงานอยู่
2. ดับเบิลคลิกตัวติดตั้ง Windows อาจเตือนว่าแอปมาจากผู้เผยแพร่ที่ไม่รู้จัก เพราะแอปไม่ได้ลงนามรหัส คลิก **ข้อมูลเพิ่มเติม** (More info) แล้วคลิก **เรียกใช้อยู่ดี** (Run anyway)
3. เลือกหนึ่งตัวเลือก:
   - **Install normally:** ติดตั้งสำหรับบัญชีผู้ใช้ของคุณโดยไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ เพิ่มทางลัดในเมนู Start และรายการในรายการแอปที่ติดตั้ง (Apps & features)
   - **Portable:** คัดลอกแอปไปยังโฟลเดอร์ที่คุณเลือก เช่น ไดรฟ์ USB จะไม่มีอะไรถูกเพิ่มในเมนู Start หรือรีจิสทรี และการตั้งค่าจะอยู่ในโฟลเดอร์ `Data` ข้างแอป
4. คลิก **Install** แล้วคลิก **Finish**

หากต้องการถอนการติดตั้งแบบปกติ ให้ใช้รายการแอปที่ติดตั้ง (Apps & features) การตั้งค่าและข้อมูลการลงชื่อเข้าใช้ของคุณจะยังอยู่ในโปรไฟล์ผู้ใช้

คุณยังดาวน์โหลด `Caption-Finder-Windows-Portable.zip` จากหน้าเดียวกันได้ ให้แตกไฟล์ ZIP ทั้งหมดลงในโฟลเดอร์ก่อน แล้วจึงเรียกใช้ `Caption Finder.exe` อย่าเรียกใช้จากภายใน ZIP

## การติดตั้ง (macOS)

รับ `Caption-Finder-Installer.dmg` จาก[รุ่นล่าสุด](https://github.com/MolecularDust/Caption-Finder/releases)แล้วเปิดขึ้นมา หน้าต่างจะแสดงขั้นตอน:

1. ดับเบิลคลิก **Install Caption Finder**
2. macOS จะหยุดไว้ (“ไม่สามารถเปิดได้”) คลิก **เสร็จสิ้น** (Done)
3. ดับเบิลคลิกไทล์สีน้ำเงิน **Open System Settings** เลื่อนไปที่ด้านล่างสุดของ **ความเป็นส่วนตัวและความปลอดภัย** (Privacy & Security) ใน **การตั้งค่าระบบ** (System Settings) แล้วคลิก **เปิดอยู่ดี** (Open Anyway)
4. ยืนยันด้วยรหัสผ่านของคุณ แล้วคลิก **ดำเนินการต่อ** (Continue) และ **ติดตั้ง** (Install)

แอปนี้ลงนามแบบ ad hoc และไม่ได้ผ่านการรับรอง (notarize) ดังนั้น macOS จึงบล็อกตัวติดตั้งหนึ่งครั้ง แอปที่ Installer วางไว้จะไม่ถูกทำเครื่องหมายว่าดาวน์โหลดมา Caption Finder เองจึงเปิดได้โดยไม่ถูกบล็อก ต้องใช้ macOS 11 หรือใหม่กว่าบน Apple silicon

## ตั้งค่าการเข้าถึง YouTube

1. ติดตั้ง Caption Finder แล้วเปิด **บัญชีและการตั้งค่า**
2. ใต้ **บัญชีของเครื่องเล่นวิดีโอ** คลิก **1. ลงชื่อเข้าใช้ Google** แล้วคลิก **2. เชื่อมต่อ YouTube** และเลือกช่องของคุณหากถูกถาม ปิดหน้าต่างบัญชีเมื่อเสร็จ
3. ใต้ **การยืนยันตัวตนสำหรับดาวน์โหลด** เลือก **เซสชัน YouTube ของแอป**

คุณพร้อมใช้ Caption Finder แล้ว

หากต้องการใช้เบราว์เซอร์ที่คุณลงชื่อเข้าใช้ไว้แล้วแทน ให้เลือกเบราว์เซอร์นั้นใต้ **การยืนยันตัวตนสำหรับดาวน์โหลด** บน Windows ให้ปิดเบราว์เซอร์นั้นก่อนค้นหา: เบราว์เซอร์ตระกูล Chromium จะล็อกไฟล์คุกกี้ขณะทำงาน ดังนั้นเซสชันของแอปเองจึงเป็นตัวเลือกที่เชื่อถือได้ที่นั่น บน macOS ไม่จำเป็นต้องปิดเบราว์เซอร์ ใช้เฉพาะบัญชีของคุณเอง อย่านำเข้าหรือแบ่งปันคุกกี้ของผู้อื่น

คุณยังคงเลือก **ไม่ระบุตัวตน** ไว้ได้ แต่การตรวจสอบบอทของ YouTube เข้มงวดกว่าสำหรับการเข้าถึงแบบไม่ระบุตัวตน และบางวิดีโอจะล้มเหลว

## วิธีใช้

**ค้นหาใน** เลือกโหมด

- **ช่อง:** พิมพ์ชื่อ แล้วรายการช่องที่ตรงกันจะปรากฏ (กด Enter เพื่อแสดงทันที) คลิกหนึ่งช่องเพื่อเพิ่ม ลิงก์ช่องหรือ `@handle` จะถูกเพิ่มโดยตรง และลิงก์วิดีโอที่วางจะแนะนำช่องที่วิดีโอนั้นอยู่ หลายช่องจะถูกค้นหาทีละช่อง หรือสลับกัน (ทีละหนึ่งวิดีโอจากแต่ละช่องตามลำดับ) ดู Account & Settings
- **วิดีโอ:** วางลิงก์วิดีโอ (watch, `youtu.be` หรือ Shorts) หนึ่งหรือหลายลิงก์ วิดีโอในรายการจะถูกค้นหาตามลำดับ

จากนั้นพิมพ์ **วลีที่ค้นหา** แล้วกด **ค้นหา** ผลลัพธ์จะปรากฏเมื่อพบ โดยรายการล่าสุดมาก่อน สูงสุด 25 วิดีโอ คลิกหนึ่งรายการเพื่อเปิด แต่ละรายการจะแสดงบรรทัดที่ตรงกันและจำนวนที่ตรงกันของวิดีโอนั้น

ทางขวา: เครื่องเล่น บรรทัดที่ตรงกัน ไทม์ไลน์ **ตั้งจุดเริ่ม / ตั้งจุดสิ้นสุด** พร้อมระยะเผื่อและความยาว **Precise Cut** **ดูตัวอย่างช่วงที่เลือก** และชื่อไฟล์ เลือกโฟลเดอร์ดาวน์โหลดแล้วเพิ่มส่วนที่เลือกลงในคิวดาวน์โหลด คิวรองรับการหยุดชั่วคราว ทำต่อ ยกเลิก ลองใหม่ และ **แสดงไฟล์** ซึ่งแสดงไฟล์ที่เสร็จแล้วใน File Explorer บน Windows หรือใน Finder บน macOS

**พรีเซ็ต** บันทึกรายการช่องหรือวิดีโอเพื่อให้คุณเรียกกลับมาได้ **บันทึกพรีเซ็ต** จะใช้ไม่ได้จนกว่ารายการจะมีข้อมูล **โหลดพรีเซ็ต** เปิดโฟลเดอร์พรีเซ็ตเพื่อเลือกไฟล์ แต่ละโหมดมีพรีเซ็ตของตัวเอง คลิกขวาที่ชื่อพรีเซ็ต: Load, Add to current list, Show in Finder, Rename และ Remove from list คลิกขวาที่พื้นที่ว่าง: Clear files, Clear presets และ Show presets folder การเอาพรีเซ็ตออกจากแถวจะไม่ลบไฟล์ของมัน บน Windows **แสดงใน Finder** ยังคงใช้ป้ายนั้น แต่จะเปิด File Explorer พร้อมเลือกไฟล์พรีเซ็ต และ **แสดงโฟลเดอร์พรีเซ็ต** จะเปิดโฟลเดอร์ใน File Explorer

### การจับคู่

- ตัวพิมพ์ใหญ่เล็ก เครื่องหมายวรรคตอน และรูปแบบอะพอสทรอฟีจะถูกละเว้น วลีหนึ่งสามารถคาบเกี่ยวหลายช่วงคำบรรยายที่อยู่ติดกัน
- ภาษาที่ไม่มีช่องว่าง (จีน ญี่ปุ่น ไทย และอื่น ๆ ที่คล้ายกัน) จะจับคู่ทีละอักขระ เครื่องหมายสระของภาษาอาหรับและฮีบรูจะถูกละเว้น
- ภาษาของคำบรรยายเป็นไปตามอักษรของวลี (วลีอักษรซีริลลิกจะมองหาแทร็กภาษารัสเซีย ยูเครน และที่คล้ายกัน) หรือภาษาที่พูดในแต่ละวิดีโอสำหรับอักษรละติน **ภาษาของคำบรรยาย** ในการตั้งค่าจะแทนที่สิ่งนี้ ซึ่งครอบคลุมแทร็กเสียงพากย์ที่บางช่องเผยแพร่ด้วย
- **ค้นหาในคำบรรยาย** จำกัดการค้นหาให้อยู่ที่คำบรรยายที่อัปโหลด คำบรรยายอัตโนมัติของ YouTube หรืออย่างใดอย่างหนึ่ง (ให้ความสำคัญกับที่อัปโหลด) ไม่มีการใช้คำแปลเลย
- ขอบเขตคือขอบเขตของช่วงคำบรรยาย ไม่ใช่การจัดแนวระดับคำ

### Account & Settings

- **บัญชีของเครื่องเล่นวิดีโอ:** **1. ลงชื่อเข้าใช้ Google**, **2. เชื่อมต่อ YouTube** (เลือกช่องของคุณหากถูกถาม) และ **ตรวจสอบการเล่น** เปิดหน้าต่างบัญชีแยกต่างหากสำหรับเครื่องเล่น การลงชื่อเข้าใช้จะเก็บไว้ในที่เก็บข้อมูลเบราว์เซอร์ของแอปเอง บน YouTube อวตารบัญชียืนยันว่าคุณลงชื่อเข้าใช้แล้ว และเมนูบัญชีใช้สลับบัญชีหรือออกจากระบบ ปิดหน้าต่างเมื่อเสร็จแล้วค้นหาอีกครั้งเพื่อโหลดเครื่องเล่นใหม่
- **การยืนยันตัวตนสำหรับดาวน์โหลด:** แหล่งที่การค้นหาคำบรรยายและการดาวน์โหลดใช้การลงชื่อเข้าใช้ YouTube เลือก **ไม่ระบุตัวตน** (ค่าเริ่มต้น), **เซสชัน YouTube ของแอป**, เบราว์เซอร์ที่แอปพบในคอมพิวเตอร์เครื่องนี้ หรือ **นำเข้าคุกกี้ Netscape…** คุกกี้จะไม่ถูกคัดลอกไปยังการตั้งค่าของแอปเลย
  - **Windows:** ตรวจพบ Chrome, Edge, Firefox, Brave, Chromium, Vivaldi และ Opera
  - **macOS:** ตรวจพบ Chrome, Opera, Vivaldi, Firefox, Safari และอื่น ๆ
- **บน Windows:**
  - ปิดเบราว์เซอร์ให้สนิท รวมถึงโปรเซสเบื้องหลัง ก่อนค้นหาหรือดาวน์โหลดด้วยคุกกี้ของมัน เบราว์เซอร์ตระกูล Chromium (Chrome, Edge, Opera, Brave, Vivaldi, Chromium) จะล็อกไฟล์คุกกี้ขณะทำงาน หากแอปแจ้งว่าคัดลอกฐานข้อมูลคุกกี้ของเบราว์เซอร์ไม่ได้ นี่คือสาเหตุ
  - การเข้ารหัสคุกกี้ของ Chromium บน Windows ยังอาจขัดขวางการดึงข้อมูล และแอปไม่เคยหลบเลี่ยงมัน ให้ใช้ **เซสชัน YouTube ของแอป** หรือ **นำเข้าคุกกี้ Netscape…** แทน
  - แอปส่งพร็อกซี HTTP แบบกำหนดเองของระบบ (ไม่มีชื่อผู้ใช้และรหัสผ่าน) ให้ yt-dlp และปฏิบัติตาม `HTTP_PROXY` และ `HTTPS_PROXY` สคริปต์ PAC หรือรายการยกเว้นที่มีรายการอื่นนอกจากที่อยู่ภายในเครื่องจะไม่ถูกส่งต่อ
  - โฟลเดอร์ดาวน์โหลดและไฟล์คุกกี้ที่นำเข้าจะถูกบันทึกเป็นพาธเต็ม หากสำเนาแบบพกพาย้ายไปไดรฟ์อักษรอื่น ให้เลือกใหม่อีกครั้ง
  - การหยุดดาวน์โหลดชั่วคราวจะระงับโปรเซสของมัน ดังนั้นการหยุดนานอาจทำให้ YouTube ตัดการเชื่อมต่อ การหยุดและทำต่อจะไม่คงอยู่หลังรีสตาร์ตแอป
  - Windows ไม่มีการเข้าถึงดิสก์แบบเต็ม (Full Disk Access) หน้าต่างช่วยเหลือของ macOS ด้านล่างจึงไม่ปรากฏเลย
- **บน macOS:** คุกกี้ของ Chrome และ Firefox ต้องใช้ **การเข้าถึงดิสก์แบบเต็ม** (Full Disk Access) แอปจะเปิดหน้าต่างช่วยเหลือเล็ก ๆ ที่มีไอคอนให้ลากไปยังการตั้งค่าระบบ (System Settings)
- **ชื่อไฟล์**ที่ Windows บันทึกไม่ได้ (ชื่อที่สงวนไว้ เช่น `CON` หรือ `NUL` และอักขระอย่าง `? * | < >`) จะถูกปฏิเสธบนทุกแพลตฟอร์ม เพื่อให้คลิปย้ายไปมาระหว่างสองระบบได้
- **จำนวนวิดีโอที่สแกนต่อการค้นหา** (ต่อช่อง ค่าเริ่มต้น 50), **ผลลัพธ์จากหลายช่อง**, **ภาษาของคำบรรยาย**, **ค้นหาในคำบรรยาย**
- **ไม่ต้องเล่นวิดีโอแรกที่พบโดยอัตโนมัติ** และ **ขณะที่วิดีโอกำลังโหลด** (ภาพขนาดย่อหรือตัวหมุน)

## ข้อมูลถูกเก็บไว้ที่ไหน

| อะไร | Windows (ติดตั้งแบบปกติ) | macOS |
| --- | --- | --- |
| การตั้งค่า (โฟลเดอร์ดาวน์โหลด การยืนยันตัวตน) | `%APPDATA%\com.mike.captionfinder\settings.json` | `~/Library/Application Support/com.mike.captionfinder/settings.json` |
| พรีเซ็ต | `%APPDATA%\Caption Finder\Presets\Channels` และ `...\Videos` | `~/Library/Application Support/Caption Finder/Presets/Channels` และ `.../Videos` |
| การลงชื่อเข้าใช้ YouTube ของแอปเอง | `%LOCALAPPDATA%\com.mike.captionfinder\EBWebView` | `~/Library/WebKit/com.mike.captionfinder` |

บน Windows แคชและบันทึกสื่อ (`logs\media.jsonl` ซึ่งมีเฉพาะรหัสวินิจฉัยที่ปลอดภัย) ก็อยู่ใต้ `%LOCALAPPDATA%\com.mike.captionfinder` เช่นกัน สำเนาแบบพกพา (ZIP แบบพกพา หรือตัวเลือก **Portable** ของตัวติดตั้ง) เก็บการตั้งค่า การลงชื่อเข้าใช้ และแคชไว้ในโฟลเดอร์ `Data` ข้าง `Caption Finder.exe` โดยบันทึกอยู่ใน `Data\Diagnostics` พรีเซ็ตของมันยังคงไปที่ `%APPDATA%\Caption Finder\Presets` ย้ายโฟลเดอร์แบบพกพาเฉพาะเมื่อปิดแอปอยู่

พรีเซ็ตถูกเก็บไว้นอกโฟลเดอร์ของแอปโดยตั้งใจ: การรีเซ็ตหรือการติดตั้งใหม่จะไม่แตะต้องมัน แอปไม่เคยลบหรือเขียนทับไฟล์พรีเซ็ตโดยไม่ถามก่อน การแทนที่ไฟล์หนึ่งจะเก็บเวอร์ชันเก่าไว้ข้างกันในชื่อ `<name>.json.bak`
